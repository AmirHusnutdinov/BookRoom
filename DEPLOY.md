# Деплой BookRoom на сервер (212.193.27.116)

Сервер: Ubuntu 24.04, Docker и Docker Compose уже установлены.
HTTPS: самоподписанный сертификат (браузер один раз покажет предупреждение).

---

## 1. Скопировать проект на сервер

С локального компьютера (из папки, ГДЕ ЛЕЖИТ архив/папка проекта):

    scp -r bookroom_final root@212.193.27.116:/root/bookroom

Либо распакуй архив локально и закинь папку. Можно через любой SFTP-клиент.

ВАЖНО: НЕ копируй локальные venv/, flask/, __pycache__ — только файлы проекта.
Файл booking.db можно скопировать (с уже импортированными аудиториями) ИЛИ
наполнить заново на сервере (см. шаг 4).

---

## 2. Зайти на сервер

    ssh root@212.193.27.116

Перейти в папку проекта:

    cd /root/bookroom

---

## 3. Создать самоподписанный сертификат

Один раз генерируем сертификат для nginx:

    openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
      -keyout nginx/certs/privkey.pem \
      -out nginx/certs/fullchain.pem \
      -subj "/CN=212.193.27.116"

(создаст два файла в nginx/certs/)

---

## 4. Запустить

    docker compose up -d --build
    docker compose ps

Должны подняться: bookroom_flask, bookroom_nginx, bookroom_docs.

Открыть в браузере:
- Приложение:   https://212.193.27.116/   (браузер предупредит про сертификат — "Дополнительно" -> "Перейти")
- Документация: http://212.193.27.116:8080/

---

## 5. Наполнить аудитории (если база пустая)

Сначала зарегистрируй админа через сайт (регистрация с кодом из ADMIN_SECRET в .env).
Затем внутри контейнера запусти импорт:

    docker compose exec web python import_next_week_from_spring.py \
      --xlsx "ОВТ АУДИТОРН.ФОНД  2025-2026 уч. год 01.02.2026-25.05.2026 уч.г..xlsx" \
      --db booking.db \
      --sheet "01.02.2026-24.05.2026 Весна. КО" \
      --reference-date 2026-02-02

---

## 6. Проверка функционала

- Регистрация / вход / бронирование / личный кабинет / календарь.
- Админка -> Настройки почты (SMTP) -> сохранить -> тестовое бронирование -> письмо.

---

## 7. Безопасность (обязательно после деплоя)

- Сменить пароль root (он засветился в переписке):
      passwd
- Убедиться, что в .env стоит FLASK_DEBUG=0 (прод).
- Если открыт фаервол — оставить только порты 22, 80, 443, 8080.
